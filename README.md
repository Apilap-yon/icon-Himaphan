## 🔌 เชื่อมกับ Google Sheet (เก็บข้อมูลผู้สมัครจริง)

ค่าเริ่มต้นระบบจะเก็บข้อมูลลง **localStorage** ของเบราว์เซอร์ (ใช้เดโม/ทดสอบได้ทันที)
หากต้องการเก็บรวมศูนย์ใน Google Sheet:

1. เปิด Google Sheet ที่จะใช้เก็บข้อมูล → เมนู **Extensions ▸ Apps Script**
2. ลบโค้ดเดิม วางเนื้อหาจาก [`apps-script/Code.gs`](apps-script/Code.gs) ทั้งหมด
3. **Deploy ▸ New deployment ▸ Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
4. คัดลอก **Web app URL** (ลงท้าย `/exec`)
5. นำไปวางในไฟล์ [`js/config.js`](js/config.js) ที่ `APPS_SCRIPT_URL`

ระบบจะสร้างชีตให้อัตโนมัติ 2 หน้า: `Registrations` และ `Volunteers`
> แม้เชื่อม Sheet แล้ว ระบบยังเก็บสำเนาใน localStorage เป็น backup เสมอ

## ✏️ การกรอกข้อมูลจากชีต "รายละเอียดกิจกรรม"

ข้อมูลบางส่วนอยู่ใน Google Sheet ต้นฉบับ (ระบบดึงอัตโนมัติไม่ได้)
แก้ไขได้ในไฟล์ [`js/data.js`](js/data.js) ของแต่ละรายการ:

| ฟิลด์ในโค้ด | ตรงกับคอลัมน์ในชีต | ความหมาย |
|-------------|--------------------|----------|
| `teacher` | **C** | ครูผู้ดูแล |
| `description` | **D** | รายละเอียดกิจกรรม |
| `prize` | **J** | รางวัล |
| `volunteerSlots` | **H** | จำนวนจิตอาสาที่รับในรายการนั้น |

ค่าที่ยังเป็นตัวอย่างจะมีคำว่า _"(กรอกจากชีต ...)"_ กำกับไว้ และมีคอมเมนต์ `TODO จาก GG Sheet`

> ⚙️ ชื่อรายการ (คอลัมน์ B) ถูกกรอกให้แล้วตามที่ระบุไว้

## ⚙️ การตั้งค่าอื่น ๆ ( `js/config.js` )

| ตัวแปร | ค่า |
|--------|-----|
| `APPS_SCRIPT_URL` | URL ของ Apps Script (ว่าง = โหมด localStorage) |
| `ADMIN_PASSCODE` | รหัสผ่านหน้าแอดมิน |
| `REGISTRATION_OPEN` | `true`/`false` เปิด-ปิดรับสมัคร |

## 📁 โครงสร้างไฟล์

```
index.html            หน้าหลัก (สมัครแข่งขัน + จิตอาสา)
admin.html            หน้าแอดมิน (ดู/ค้นหา/ส่งออก CSV)
css/style.css         ธีมป่าหิมพานต์ / RPG
js/config.js          ตั้งค่า backend และระบบ
js/data.js            ข้อมูลการแข่งขันทั้งหมด  ← แก้ข้อมูลจากชีตที่นี่
js/storage.js         ชั้นจัดเก็บข้อมูล (Apps Script + localStorage)
js/app.js             ตรรกะหน้าเว็บ
apps-script/Code.gs   โค้ดหลังบ้านสำหรับ Google Apps Script
assets/img/           รูปภาพ (พื้นหลังป่าหิมพานต์ + ไอคอน)
```
